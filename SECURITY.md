# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately to the maintainer, @AndyTuttle12. If this repository is public, use
GitHub's private vulnerability reporting (Security tab, "Report a vulnerability").

Include what you found, how to reproduce it, and its impact. You will get an
acknowledgement within 7 days.

## Supported versions

Only the latest commit on `main` is supported.
